# Note-structuring AI Agent

An LLM-based tool that takes raw (unstructured) text, identifies informations that can be expanded, and then gives back structured and expanded text. It may be useful for studying, when you have to write notes quickly.  


## Setup guide

Install Poetry to install all the dependencies
`pip install poetry`

Then install the project dependencies
`poetry install`
